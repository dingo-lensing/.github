## dingo-lensing

Dingo-lensing is a codebase for gravitational-wave lensing data analysis that exploits the latest developments in deep learning and simulation-based inference. 
It builds on top of [DINGO (Deep Inference for Gravitational-wave Observations)](https://github.com/dingo-gw). 

For further information about contributing to dingo-lensing, please see [CONTRIBUTING.md](https://github.com/dingo-lensing/dingo-lensing/blob/main/CONTRIBUTING.md).
